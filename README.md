# 风经过的小站

一个适合手机阅读和编辑的中文个人博客。文章、相册、头像和站名都可以在中文后台维护。初始化内容是三篇开站示例和两本原创插画集，可以替换。

## 阅读和管理

- [公开主站](https://wind-journal-25341.pages.dev/)
- [备用阅读站](https://2534179170-design.github.io/personal-blog/)
- [站主管理入口](https://wind-journal-25341.pages.dev/admin/)
- [自动部署记录](https://github.com/2534179170-design/personal-blog/actions)

### 写文章

1. 在后台用自己的 GitHub（代码托管平台）账号登录，点「文章 → 新建文章」。填写标题、日期、摘要、标签和正文，使用工具栏插入图片、引用或小标题。
2. 编辑时草稿保存在本机当前浏览器。点「预览」查看效果；再次进入后台可点「继续草稿」。换设备、换域名或清除浏览数据会影响草稿访问。
3. 点「发布」后查看状态。「已上线」表示主站的公开版本已经包含这次内容。期间可以关掉页面，再回来继续查看。若提示其他设备已修改，请先复制自己的修改，再丢弃旧草稿并重新编辑最新版本。

### 相册和资料

- 点「相册 → 新建相册」，填标题、日期和说明，选择照片。上传前会在浏览器重新绘制为 WebP（压缩图片格式），去除原文件的定位和拍摄信息。大图最长边 1600 像素，缩略图最长边 480 像素。
- 可以上下移动照片并添加说明。每批最多 18 张新相片，单次约 20 MB；相册发布后可继续追加。原片由自己保管。
- 点「个人资料 → 编辑」可改昵称、签名、介绍、社交链接、头像、首页风景和站名。修改后需要发布。
- 撤下文章或相册后，下一次成功部署会移除公开详情页；无人引用的上传图片也会从该次部署移除。公开仓库历史、旧部署和第三方副本可能留存之前发布的内容。

## 首次配置站主登录

托管平台使用 Cloudflare Pages（免费网页托管）。站主授权通过单仓库 GitHub 应用完成，与部署密钥分开。

1. 在已登录站主账号的电脑上进入项目目录，运行下面的命令。向导只监听本机，打开的页面会引导你前往 GitHub 创建应用。
2. 点击「Create GitHub App（创建应用）」，返回本机页面后点安装。选择「Only select repositories（仅指定仓库）」，仅勾选 `personal-blog`。若应用已建立但尚未安装，可到 GitHub 个人设置中的开发者设置打开该应用并安装。
3. 完成后运行第二条命令，将密钥写入主站托管设置，并部署生效。本机配置保存在被版本管理忽略的 `.local` 目录中。

```powershell
python scripts/setup-login.py --origin https://wind-journal-25341.pages.dev --owner 2534179170-design --owner-id 227329273
.\scripts\configure-login.ps1
```

已有向导正在运行时请使用已打开的页面。后台只允许数字账号编号匹配的站主发布；退出后需重新授权。访客可以浏览或在自己的设备试写草稿。

## 空间、相册与同好功能

- 编辑空间时，选中正文里的文字或图片标记，再点「折叠剧透」。可把「含剧透，点击展开」改成章节提示。首页显示单独填写的摘要，封面请选适合直接展示的图片。
- 编辑相册时填写分类。给某张照片填写剧透提示，会隐藏缩略图和说明，并在前后切换大图时询问是否展开。
- 编辑空间或相册时点「添加关联作品」，填写作品名和番组计划条目编号。例如作品网址以 `/subject/123` 结尾，编号即 `123`。绑定同一编号的内容会汇总到一个作品页。
- 在「个人资料」里维护首页一句话近况、同好友链、年度最爱。留空的近况不会出现在首页。
- 页脚可进入「年度回顾」与「同好友链」。年度回顾的空间和相册按发布日期归年。点「读取番组计划记录」后，可查看公开的看过与玩过清单，并切换年份。番组计划提供收藏最后更新时间，修改旧作品评分可能改变它所属的统计年份。

## 设置主站自动部署

「同步番组计划日志与短评」自动任务每天检查账号 `828732` 的公开日志和超过 300 字的动画短评。新增或修改的内容会写进仓库并发布到备用站。收藏状态和集数在网页打开时读取。主站的定时发布需要下文的 `CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID` 和 `CLOUDFLARE_PROJECT`，配置后同一自动任务也会更新主站。

GitHub Pages（备用网页托管）通过仓库自动任务发布。Cloudflare 主站使用同一仓库的「更新主站」自动任务直接上传，两个站的资源各自托管。

1. 打开 [Cloudflare 令牌管理页](https://dash.cloudflare.com/profile/api-tokens)，选择「Create Token（创建令牌）」及自定义令牌，权限仅选「Account → Cloudflare Pages → Edit（账号 → 网页托管 → 编辑）」，资源仅选当前账号。
2. 到[仓库部署密钥设置](https://github.com/2534179170-design/personal-blog/settings/secrets/actions/new)新建 `CLOUDFLARE_API_TOKEN`，值为刚生成的令牌。在官方页面直接填写。
3. 仓库变量 `CLOUDFLARE_ACCOUNT_ID` 表示托管账号编号，`CLOUDFLARE_PROJECT` 为 `wind-journal-25341`，`PRIMARY_ORIGIN` 为主站根地址。进入「Actions（自动任务）→ 更新主站 → Run workflow（运行任务）」执行一次。后续推送到 `main` 会自动发布。
4. 备用站在仓库「Settings（设置）→ Pages（网页托管）」中选择「GitHub Actions（自动任务）」作为部署来源。

日常更新仅使用免费套餐，无自购域名。网站容量接近 1 GB 时应关注相册体积；后台根据仓库容量给出提示。免费额度和运行状态可在各自平台查看。

## 本地预览和恢复

开发工具使用 Node.js 24（网站构建运行环境）和 pnpm 11（依赖管理工具）。在项目目录运行：

```powershell
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm build
```

预览网址以终端显示为准。本地静态预览支持编辑草稿及预览；正式登录和写入由主站的服务端接口提供。

- 部署失败时，查看对应自动任务的失败步骤，修复后重新运行。主站显示的已发布版本可在 `/version.json` 查看，失败的构建不会替换上一次成功部署。
- 恢复旧版时，先同步仓库，在 Git（版本管理工具）中用 `git revert <提交编号>` 为目标更新创建反向提交，再推送。两个站都会按恢复后的内容重新构建。也可以在 Cloudflare 的「Deployments（部署）→ Rollback（回滚）」暂时恢复指定主站版本，然后同步修正仓库。
- 文章保存在 `content/posts`，相册和资料保存在 `content`，公开图片在 `public`。克隆仓库即可备份已发布内容。尚未发布的草稿另保存在编辑设备上。

## 大陆手机网络验收

用手机关闭无线网和代理，使用移动数据分别打开两个站。依次检查首页封面、一篇文章、一张相册大图和复制出的分享链接。记录测试日期、运营商、两个地址能否打开和图片能否加载，以实测结果选择分享地址。
